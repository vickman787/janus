What Janus is

A restart safe onchain execution agent.

problemAn agent running a multi step onchain operation can crash mid way. Memory can be stale. The chain may have moved. Guessing is dangerous.
answerRemember what happened in Sibyl Memory. Revalidate against Base mainnet before every step. Act only when the two agree.
ruleSibyl tells Janus what happened before. Base tells Janus what is true now.

Why memory is load bearing

The deletion test.

with memoryA fresh process restores the operation by id, reconciles, and continues safely.
without memoryJanus can still read the chain, but it has lost the operation identity, the target, the completed steps, and the invariants. It refuses.
resultNO EXECUTION CHECKPOINT FOUND. AUTOMATIC RESUME REFUSED.

The three verdicts

consistentLive state matches the checkpoint. Exactly one continuation is safe.
mismatchThe chain moved while the agent was offline. Janus refuses and names the broken invariant. See op_demo_mismatch.
no checkpointSibyl holds no record for the operation. Automatic resume is refused.
